# 🚀 Code Editor & Visualizer

An interactive AI-powered code editor and execution platform designed to help developers write, execute, visualize, and understand code more effectively. The project aims to bridge the gap between coding and algorithm understanding through real-time execution, visualization, and AI-assisted explanations.

---

## 📌 Project Overview

Code Editor & Visualizer is a modern web-based development environment that allows users to:

* Write code in multiple programming languages
* Execute code directly from the browser
* Provide custom input for programs
* View execution output in real time
* Interact with an AI assistant for code understanding
* Visualize program execution and algorithms (upcoming)

The long-term vision is to create a platform that not only runs code but also helps developers understand *how* their code works internally.

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Move Into Project

```bash
cd Code-editor-and-visualizer
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
